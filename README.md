# UzooAI — AI 无限画布与漫剧创作平台

UzooAI（简称 Uzoo）是一站式 AIGC 创作平台，在无限画布中连接剧本、角色参考、分镜、图像与视频，帮助创作者组织素材、探索想法并推进视觉内容创作。

本仓库用于发布 UzooAI 的产品介绍、官方入口与使用指南，不包含平台业务源码。

## 官方入口

- [UzooAI 官网](https://aigc.uzooai.com/)：了解平台功能与创作方式
- [创作工作台](https://www.uzooai.com/workspace)：浏览公开案例与作品，开始创作
- [账号登录](https://www.uzooai.com/auth/login)：登录后使用个人创作功能

## 你可以用 UzooAI 做什么？

### 在无限画布上组织创作

将文本、参考图片和视频素材放在同一个空间中，通过节点与连线梳理创作关系，比较不同结果，逐步迭代想法。

[了解 AI 无限画布](https://aigc.uzooai.com/features/infinite-canvas/)

### 连接漫剧创作流程

围绕故事与镜头组织剧本、角色参考、分镜和视频素材，让不同创作阶段在同一张画布中保持联系。

[了解 AI 漫剧创作](https://aigc.uzooai.com/solutions/ai-comic/)

### 浏览公开案例与作品

进入工作台，查看公开案例和只读画布，了解平台的操作方式与创作效果，再开始自己的项目。

[浏览工作台](https://www.uzooai.com/workspace)

## 如何开始？

1. 打开官网，了解平台功能。
2. 进入工作台，浏览公开案例与作品。
3. 登录账号，创建个人项目。
4. 根据创作目标组织文本、图像与视频，逐步完成内容。

具体可用模型、生成能力和用量规则以工作台实际展示为准。

## 常见问题

### 浏览案例需要登录吗？

公开工作台支持游客浏览。个人项目及需要账号身份的创作操作需要登录。

### 官网和工作台有什么区别？

官网提供产品介绍与功能说明；工作台用于浏览样例、管理项目和执行创作。

### Uzoo 和 UzooAI 是同一个平台吗？

是的，本仓库中 Uzoo 是 UzooAI 的简称。
